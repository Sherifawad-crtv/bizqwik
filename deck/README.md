# Bizqwik sales deck

The 15-slide product and pricing deck: the five apps (founder, accountant,
front desk, coach, member app), the four plans and add-ons, and the closing
contact slide.

- `Bizqwik-Deck.pdf`: the finished deck, ready to send.
- `index.html` + `deck.css` + `assets/`: the editable source.
- `build.py`, `render.mjs`: rebuild the slides and export the PDF.
- `screenshot-specs/`: Playwright scripts that capture the app screenshots
  used on the slides (`assets/shots/`).

This branch only holds the deck; it is not part of the app and is never merged
into `main`.
